# D21 — 快速閉集合相似度探針：可分性數字 + 獨立審查追蹤

**⚠️ 全部合成資料，不是真實準確率。** 真實結論待板子接頭修好、真的錄完
N 個選項後用 `analysis/experiments/exp_d21_closed_set_probe.py --session`
模式重跑。

寫這份報告的理由：`HANDOFF.md` §4.4「任何值得記住的量測，當下就寫進檔案，
寫在訊息裡等於沒寫」——D21 的可分性數字之前只活在完成回報訊息跟 commit
訊息裡，`esp-mask-test-18` 的跨報告稽核查無出處，這裡補上。

## 獨立審查（`esp-mask-test-22`，沒寫過這支程式的人）

**結論：可以信。** 查過的五項都乾淨：兩個 VAD 都失效會報錯
（`NoSpeechDetectedError`）、`silent` 模式只用唇動、可分性比值的分母
（同類自距離中位數）、隨機基準 `(N+1)/2`、以及誠實回報「沒過 1.5 門檻」
——沒找到會安靜給錯答案的路徑。

`22` 另外指出並確認的一個驗證狀態（不是問題，記錄用）：
`require_speech_window()`「三個 VAD 來源全滅才報錯」這條路徑邏輯正確、
有單元測試覆蓋，但**目前沒有真實資料真的走過這條最極端的分支**——今天
`8f` 在真機上遇到的是單一來源（ToF-A）失效，不是三個全滅。見下方
「需要人工驗證」。

## 22 發現的缺口：demo 輸出沒把關鍵證據顯示出來

`--demo` 模式的 stdout 報告 + 存的 JSON，**原本沒有把「距離確實擠成一團」
這件事算出來顯示**——trimmed 跟 untrimmed 兩次 demo 跑出來的 top1 排名
都是第一名（因為 demo 用的合成訊噪比刻意調很高，6 倍），只看 demo 的
排名輸出容易誤以為「裁不裁切沒差」。

**這不是 bug，是溝通層缺口**：真正嚴謹的證明其實在
`analysis/similarity/test_closed_set_probe.py` 的
`test_untrimmed_probe_scores_collapse_near_uniform` 裡（用未正規化的原始
距離離散係數當量尺，並在測試註解裡解釋了為什麼不能用 `fused` 軌的正規化
距離——`normalize_distances()` 永遠會把輸出拉開到差不多的範圍，不管輸入
本身擠不擠，見 `closed_set_probe.py` 的說明）。但 story 明訂 demo 對照
輸出是「留給未來的人的證據」，一份看不出結論的證據不算證據。

**已修**（`exp_d21_closed_set_probe.py` 的 `run_probe()`）：payload 新增
`raw_distance_cv`（ToF 軌 euclidean 原始距離的 `std/mean`）與
`top1_margin`（rank1 到 rank2 的距離差），trimmed/untrimmed 各存一份；
stdout 也印出來。

## 數字（`--demo` 重跑，跟 22 核對過，數字一致）

| | ToF raw distance 離散係數（std/mean） | rank1→rank2 margin |
|---|---|---|
| trimmed | 0.1143 | 15.34 |
| untrimmed | 0.0247 | **1.33**（縮小 **11.5 倍**） |

margin 從 15.34 掉到 1.33——這是最直觀的一個數字：裁切前，正確答案雖然
還是排第一，但赢第二名只赢了 1.33（跟距離本身的量級相比幾乎沒有安全
邊際，換一次雜訊抽樣結果就可能翻掉）；裁切後贏 15.34，是完全不同量級
的可靠度。**排名相同（都是第一名）掩蓋了這個差距，這正是 22 指出的
缺口本身。**

## 可分性比值（原本只在訊息裡，這裡補上出處）

`separability_ratio()`（最近的異類距離 / 同類自距離的中位數，`>1.5`
才算真的可分）：

| | 範圍 |
|---|---|
| 未裁切 | ~1.0–1.09（幾乎不可分） |
| 裁切後 | ~1.23–1.37（有改善，但這組合成詞沒有過 1.5 的門檻） |

⚠️ **但書（誠實回報，不要誤讀成「D21 這個工具測出真實詞彙集分不開」）**：
這組合成詞的 class 訊號用的是**純隨機單位向量**（`_class_signature()`），
沒有刻意做得很好分——**這個數字反映的是這批合成測試資料本身的可分性，
跟真實詞彙集（例如 vocab.json 裡實際的圓唇/展唇/擦音組合）的可分性
完全無關**。真實詞彙是刻意挑過、物理上動作不同的音，不應該假設一樣
難分。
