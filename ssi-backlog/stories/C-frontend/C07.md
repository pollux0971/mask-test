# C07 — 監測模式：signal rate 熱力圖

| 欄位 | 值 |
|---|---|
| **軌道** | C 前端 |
| **Epic** | E4 儀表板 |
| **估時** | 1.5 h |
| **前置** | `C05`, `A02` |
| **阻擋** | 無 |
| **需要硬體** | 否 |
| **可平行於** | A/B/D 軌全部 |

## Story

**As a** 研究者
**I want** 切換顯示距離或訊號強度
**so that** 我能判斷哪個通道對唇形變化更敏感

## 為什麼是這個順序

signal rate 帶的是反射率資訊——嘴唇張開露出口腔（低反射）vs 閉合（皮膚高反射）的對比，往往比距離乾淨。這個直覺需要用眼睛驗證過才敢寫進論文。

## 範圍

**包含**
- 按 `S` 在距離 / signal rate 間切換
- signal rate 用不同色系（避免與距離混淆）
- 兩者可並排顯示（四張熱力圖）

**不包含**（避免範圍蔓延）
- 定量的 SNR 比較（D11 負責）

## 實作

並排四張圖（A距離 / A訊號 / B距離 / B訊號）在 1080p 上剛好排得下 2×2，而且**一眼就能看出哪個通道訊號強**。這個視覺比較會直接影響 D01 的特徵設計決策。

signal rate 的動態範圍很大（kcps/spad 可能從個位數到數千），建議用 log 色階。
