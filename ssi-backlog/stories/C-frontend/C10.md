## Story

**As a** 研究者與 Demo 觀眾
**I want** 看到高維 ToF 特徵投影到 2D 的即時移動軌跡
**so that** 我能直觀感受不同唇形是否落在不同區域

## 為什麼是這個順序

這是離線 t-SNE（D17）的即時版本。而且它是**很好的 Demo 視覺元素**——說話時看到光點往某一團移動，比長條圖有說服力得多。

## 範圍

**包含**
- 用 session baseline + 一小段自由說話擬合 PCA(2)
- 即時投影並畫拖尾軌跡（最近 2 秒，越新越亮）
- 已 enroll 的詞（D08）用不同顏色的信賴橢圓標在背景
- 顯示 PC1 + PC2 的解釋變異比例

**不包含**（避免範圍蔓延）
- PCA 擬合演算法（D03 提供，前端只做矩陣乘法）

## 實作

PCA 投影就是 `(x - mean) @ components.T`，前端做這個矩陣乘法完全沒問題（32×2 的矩陣）。**模型參數由 D03 算好透過 API 給前端**，前端不做擬合。

拖尾用一個固定長度的點陣列 + 逐點降低 alpha。不要用 canvas 的 `globalAlpha` 疊加（會產生殘影累積），直接每幀清空重畫 60 個點。

**解釋變異比例要顯示。** 如果 PC1+PC2 只解釋 30% 的變異，那這張 2D 圖看起來的分離度就不能盡信——這個數字讓你（和口試委員）知道該用多少信心看這張圖。
