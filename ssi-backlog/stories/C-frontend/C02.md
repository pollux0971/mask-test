# C02 — 側邊欄模式切換器

| 欄位 | 值 |
|---|---|
| **軌道** | C 前端 |
| **Epic** | E4 儀表板 |
| **估時** | 2.5 h |
| **前置** | `C01` |
| **阻擋** | `C03`, `C04` |
| **需要硬體** | 否 |
| **可平行於** | A/B/D 軌全部 |

## Story

**As a** 使用者
**I want** 在側邊欄點選或按數字鍵切換五種模式
**so that** 我能快速在監測與測驗之間來回，不用重新載入頁面

## 為什麼是這個順序

這是你明確指定的需求。切換必須夠快夠明確——Demo 時你會需要在「監測模式展示訊號」與「測驗模式展示辨識」之間切好幾次。

## 範圍

**包含**
- 五個模式項目，每個有圖示 + 名稱 + 數字快捷鍵標示
- 鍵盤 `1`–`5` 切換
- 當前模式高亮
- 切換動畫（150 ms 淡入，不要更長）
- 側邊欄可摺疊成只剩圖示（Demo 投影時省空間）

**不包含**（避免範圍蔓延）
- 各模式的內容
- 狀態保存（C03）

## 實作

```
┌──────────────────┐
│ ● 已連線  proto2 │   ← C04 負責內容
├──────────────────┤
│ ▣  監測      1   │   ← 即時熱力圖、波形、品質
│ ⏺  錄製      2   │   ← trial 蒐集、enrollment
│ ◎  測驗      3   │   ← 8 選項閉集合 Demo
│ ⚗  驗證      4   │   ← 實驗執行與報告
│ ▶  回放      5   │   ← session 重播
├──────────────────┤
│ 掉幀   0.2%      │   ← C04 迷你品質摘要
│ 對稱   8%        │
│ 30.1 Hz          │
├──────────────────┤
│ ⚙  設定          │
└──────────────────┘
```

**摺疊功能不是裝飾**：Demo 投影時 200px 的側邊欄會吃掉可觀的畫面寬度，而測驗模式的三軌評分需要橫向空間。按 `\` 摺疊。

**鍵盤快捷鍵要在輸入框有焦點時停用**，否則錄製模式填 metadata 時打「3」會跳到測驗模式。用 `e.target.tagName` 檢查。

圖示用 inline SVG 或 Unicode 字元，不要引入圖示套件（維持零建置）。

## 驗收條件

- [ ] 點擊與數字鍵都能切換，效果一致
- [ ] 輸入框有焦點時數字鍵不觸發切換
- [ ] 切換耗時 < 150 ms，無閃爍
- [ ] 摺疊狀態記在 `sessionStorage`（重新整理後保持）
- [ ] 當前模式在視覺上一眼可辨
