# C08 — 監測模式：Mel 頻譜瀑布圖

| 欄位 | 值 |
|---|---|
| **軌道** | C 前端 |
| **Epic** | E4 儀表板 |
| **估時** | 3 h |
| **前置** | `C03`, `T05` |
| **阻擋** | `C19` |
| **需要硬體** | 否 |
| **可平行於** | A/B/D 軌全部 |

## Story

**As a** 研究者
**I want** 滾動顯示的 log-Mel 頻譜圖
**so that** 我能即時確認麥克風抓到了有意義的頻譜結構

## 為什麼是這個順序

RMS 波形只告訴你音量。頻譜圖讓你看見「四」的高頻擦音與「五」的低頻共振——這個差異就是辨識引擎要用的東西，肉眼先確認得到才安心。

## 範圍

**包含**
- Canvas 逐列繪製，向左捲動，保留約 5 秒
- `putImageData` 平移 + 只畫新列（不要整張重畫）
- 色階用單調亮度配色（viridis 或 magma）
- 疊加 VAD 起訖線（B15/B16）
- 無 Mel 時退化為 RMS 包絡並標示「Mel 未啟用」

**不包含**（避免範圍蔓延）
- 測驗模式的輸入縮圖（C19 復用此模組）

## 實作

```js
// 平移已有像素，只畫最右邊一列
ctx.putImageData(ctx.getImageData(1, 0, w-1, h), 0, 0);
drawColumn(w - 1, melFrame);
```

**「無 Mel 時退化」不是可有可無。** A12 有可能因為 A10 的 spike 結果而永遠不做——這個模組必須在只有 `$M` 的情況下仍然有用。退化版顯示 RMS 包絡（就是現有的波形圖），並明確標示狀態。

VAD 線疊加讓你能直觀檢查 B15 的閾值調得對不對，比看數字快得多。
