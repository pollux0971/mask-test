| **估時** | 2 h |

| **需要硬體** | 否 |
| **可平行於** | A/B/D 軌全部 |

## Story

**As a** Demo 演示者
**I want** 用滑桿即時調整 ToF 與音訊的融合權重，並重算已有的結果
**so that** 我能當場證明純 ToF 也認得出來

## 為什麼是這個順序

**這是 Demo 腳本第二步與第三步的操作介面。** 把滑桿推到純 ToF、再念一次「五」仍然對——這一個動作比十張投影片有說服力。

## 範圍

**包含**
- 0–1 連續滑桿，兩端標示 ToF / 音訊
- 拖動時**重算已存在的結果**（不需重念）
- 三個預設快捷鍵：`T` 純 ToF、`M` 純音訊、`F` 平衡
- 當前 w 值大字顯示

**不包含**（避免範圍蔓延）
- 融合演算法（D07）

## 實作

**「不需重念」是這個 story 的核心。** 上一次辨識的三軌距離向量要保留在前端，滑桿一動就是重算 `d_fused = w·d_ToF + (1-w)·d_Mel` 並重排——純前端運算，< 5 ms。

如果每動一次滑桿都要重念，Demo 的節奏會完全垮掉。

三個快捷鍵讓你在 Demo 時不用精確拖曳滑桿（投影時滑鼠操作很容易失手）。按 `T` 直接跳到純 ToF。

滑桿要**有段落感**：0.0 / 0.5 / 1.0 三個位置加吸附，其他位置自由。

## 驗收條件

- [ ] 拖動滑桿即時重排三軌，無需重念
- [ ] 重算延遲 < 50 ms
- [ ] `T` / `M` / `F` 快捷鍵正確
- [ ] 當前 w 值清楚可見
