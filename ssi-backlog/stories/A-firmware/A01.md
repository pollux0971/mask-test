# A01 — $T 行：新標籤 + 序號 + 裝置時間戳

| 欄位 | 值 |
|---|---|
| **軌道** | A 韌體 |
| **Epic** | E1 訊號地基 |
| **估時** | 2 h |
| **前置** | `T01` |
| **阻擋** | `A02`, `A05`, `B01` |
| **需要硬體** | 是（燒錄驗證） |
| **可平行於** | B/C/D 軌全部 |

## Story

**As a** 主機端分析程式
**I want** 每一行 ToF 資料都帶 `seq` 與 `t_us`
**so that** 我能重建真實時間軸並偵測掉幀

## 為什麼是這個順序

沒有時間戳，跨模態對齊就是猜的。E5 的 SNR / CV / Silhouette 全部建立在「這一幀 ToF 對應那一段音訊」的假設上——這是整條依賴鏈的根。

## 範圍

**包含**
- `print_tof_line()` 改輸出 `$T,<letter>,<seq>,<t_us>,<dim>,...`
- 每顆感測器獨立的 `seq` 計數器
- 時間戳取樣點移到 `check_data_ready()` 回傳 true 的當下

**不包含**（避免範圍蔓延）
- signal rate（A02）
- 掉幀計數（A05）
- $M 行（A03）

## 實作

檔案：`main/vl53l7cx_test.c`

關鍵是**時間戳取樣的位置**。目前的迴圈長這樣：

```c
uint8_t status = vl53l7cx_check_data_ready(&s_dev[i], &ready);
if (status == 0 && ready) {
    status = vl53l7cx_get_ranging_data(&s_dev[i], &s_results[i]);
    if (status == 0) print_tof_line(pins[i].letter, &s_results[i]);
}
```

`get_ranging_data()` 要透過 I²C 搬 4×4×多欄位的資料，@400 kHz 大約 2–4 ms。如果在 `print_tof_line()` 裡面才取時間戳，這 2–4 ms 就變成系統性偏差。

```c
if (status == 0 && ready) {
    int64_t t_us = esp_timer_get_time();      /* ← 在這裡取 */
    status = vl53l7cx_get_ranging_data(&s_dev[i], &s_results[i]);
    if (status == 0) {
        print_tof_line(pins[i].letter, s_seq[i]++, t_us, &s_results[i]);
    }
}
```

`s_seq[]` 宣告成 `static uint32_t s_seq[NUM_SENSORS]`。用 `PRId64` 印 int64。
