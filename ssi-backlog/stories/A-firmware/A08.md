# A08 — SENS 指令：感測器獨立開關

| 欄位 | 值 |
|---|---|
| **軌道** | A 韌體 |
| **Epic** | E1 訊號地基 |
| **估時** | 2 h |
| **前置** | `T01` |
| **阻擋** | `B18`, `E02` |
| **需要硬體** | 是 |
| **可平行於** | B/C/D 軌全部 |

## Story

**As a** Crosstalk 實驗
**I want** 執行期關掉單顆感測器
**so that** 我能比較「A 單獨」vs「A+B 同時」而不用重新燒錄

## 為什麼是這個順序

實驗 C₀ 需要在同一次戴上、同一個環境下做三組量測。如果每次切換都要重新燒錄，戴法早就跑掉了，量到的差異分不清是 crosstalk 還是戴法變動。

## 範圍

**包含**
- `main/uart_cmd.c` 解析 `SENS:A=0` / `SENS:B=1`
- 呼叫 `vl53l7cx_stop_ranging()` / `start_ranging()`
- 狀態變更後回一行 `$STATUS`

**不包含**（避免範圍蔓延）
- 時間多工模式（若 C₀ 失敗才做）

## 實作

**關鍵：必須真的 `stop_ranging()`，不能只是跳過 printf。**

```c
/* 錯誤做法 */
if (!s_enabled[i]) continue;   /* VCSEL 還在打，crosstalk 依然存在 */

/* 正確做法 */
vl53l7cx_stop_ranging(&s_dev[i]);
```

只跳過輸出的話，B 的雷射還在照射，A 收到的干擾一模一樣——實驗會得出「沒有 crosstalk」的錯誤結論，而這正是你要驗證的東西。

重新 `start_ranging()` 後感測器需要約 1–2 個 ranging period 才穩定，第一幀建議丟棄。

## 驗收條件

- [ ] `SENS:B=0` 後用手機相機（能看到近紅外）確認 B 的光點確實熄滅
- [ ] A 的 `seq` 在 B 開關期間不中斷
- [ ] `SENS:B=1` 後 2 秒內恢復輸出
- [ ] 重啟後的第一幀被標記或丟棄
