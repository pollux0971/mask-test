## Story

**As a** 特徵工程
**I want** ToF 同時輸出訊號強度
**so that** 特徵維度達到設計的 64 通道，且能捕捉反射率變化

## 為什麼是這個順序

距離只告訴你唇面多遠。signal rate 帶的是反射率與入射角——嘴唇張開露出口腔（低反射）vs 閉合（皮膚高反射）在 signal rate 上的對比往往比距離乾淨。你的 v3.3 簡報已經把它算進通道數，但韌體沒送。

## 範圍

**包含**
- 在 `$T` 行的距離值後面接 `dim²` 個 signal rate 值
- `signal_per_spad / 100` 取整數
- 無效 zone 同樣填 `-1`

**不包含**（避免範圍蔓延）
- `range_sigma_mm`（暫不輸出）
- `ambient_per_spad`（A06 放進心跳行）

## 實作

`VL53L7CX_ResultsData` 已有這些欄位（`vl53l7cx_api.h:300-363`）：

```c
uint32_t signal_per_spad[64 * NB_TARGET_PER_ZONE];  /* kcps/spad */
uint16_t range_sigma_mm[...];
uint32_t ambient_per_spad[64];
uint8_t  reflectance[...];
```

```c
for (int i = 0; i < n; i++) {
    uint8_t st = res->target_status[i];
    printf(",%d", (st == 5 || st == 9)
                  ? (int)(res->signal_per_spad[i] / 100) : -1);
}
```

**頻寬檢查**：4×4 下單行從 ~85 bytes 變成 ~145 bytes，兩顆 @30 Hz = 8.7 KB/s，佔 460800 baud（46 KB/s）的 19%。仍有餘裕，但 8×8 模式下單行接近 800 bytes，要在 A15 一併回歸測試。
