# A11 — Mel 濾波器組靜態表

| 欄位 | 值 |
|---|---|
| **軌道** | A 韌體 |
| **Epic** | E3 音訊特徵 |
| **估時** | 2 h |
| **前置** | `A10`, `T03` |
| **阻擋** | `A12` |
| **需要硬體** | 是 |
| **可平行於** | B/C/D 軌全部 |

## Story

**As a** 裝置端 Mel 計算
**I want** 一份編譯期就算好的三角濾波器組
**so that** 每個音框不用重算濾波器，只做乘加

## 為什麼是這個順序

40 個三角濾波器 × 257 個 bin 若每幀重算，@62.5 Hz 會吃掉可觀的 CPU。預先算成靜態表後，每幀只剩稀疏乘加。

## 範圍

**包含**
- 用 Python 依 T03 規格產生 C 陣列（`mel_filterbank.h`）
- 稀疏表示：每個濾波器只存非零 bin 的起訖與權重
- 產生腳本納入版控，可重跑

**不包含**（避免範圍蔓延）
- log 與輸出（A12）

## 實作

```python
# tools/gen_mel_table.py  → main/mel_filterbank.h
import librosa, numpy as np
fb = librosa.filters.mel(sr=16000, n_fft=512, n_mels=40,
                         fmin=80, fmax=8000, htk=False, norm='slaney')
```

稀疏格式（40 個濾波器加起來大約只有 500 個非零項，比 40×257 的密集表小 20 倍）：

```c
typedef struct { uint16_t start, len; const float *w; } mel_filter_t;
```

**用 T03 指定的 `htk=False`（Slaney）。** 這是 A12 驗收條件「與 librosa 相關係數 > 0.95」能否達成的關鍵，也是最容易搞錯的一個參數。

## 驗收條件

- [ ] 產生的表與 librosa 的 `mel()` 輸出逐元素誤差 < 1e-6
- [ ] 表的大小 < 4 KB
