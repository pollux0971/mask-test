# A13 — MEL 指令：串流開關

| 欄位 | 值 |
|---|---|
| **軌道** | A 韌體 |
| **Epic** | E3 音訊特徵 |
| **估時** | 0.5 h |
| **前置** | `A12` |
| **阻擋** | `B18` |
| **需要硬體** | 是 |
| **可平行於** | 全部 |

## Story

**As a** 8×8 高解析度模式的使用者
**I want** 能關掉 Mel 串流
**so that** 頻寬留給 ToF

## 為什麼是這個順序

8×8 模式下 `$T` 單行接近 800 bytes，兩顆 @10 Hz = 16 KB/s，加上 Mel 的 15.6 KB/s 逼近上限。要能取捨。

## 範圍

**包含**
- 解析 `MEL:0` / `MEL:1`
- 預設開啟
- 狀態反映在 `$STATUS`

**不包含**（避免範圍蔓延）

## 實作

一個 `static volatile bool s_mel_enabled = true;` 加上 `mic_task` 裡的一個 if 即可。

順帶把「目前頻寬使用率」加進 `$H`——韌體知道自己每秒印了多少 bytes，這個數字比主機端估算準確，而且能在 panel 上直接顯示還剩多少餘裕。

## 驗收條件

- [ ] `MEL:0` 後 `$F` 停止，`$M` 繼續
- [ ] 切換不影響 ToF
- [ ] `$STATUS` 反映當前狀態
