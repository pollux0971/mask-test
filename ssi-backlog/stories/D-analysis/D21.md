## Story

**As a** 研究者
**I want** 當場錄下 N 個選項各一段（3–4 秒），再念其中一個，讓程式排出相似度
**so that** 我在投入 `E05` 的 4 小時資料蒐集之前，先用 5 分鐘知道 ToF 到底有沒有攜帶詞彙資訊

## 為什麼是這個順序

這是 `E6` 完整流程的**簡化前導版**，不是取代它。

| | `D21` 快速探針 | `D08` + `E06` 正式 enrollment |
|---|---|---|
| 樣板數 | 每類 1–3 筆 | 每類 8 筆 |
| 錄製時間 | 30 秒 – 2 分鐘 | 5 分鐘 |
| LOOCV | **做不了**（樣本太少） | 可以 |
| 用途 | **早期風險偵測** | Demo 與論文數字 |

它的真正價值在於**提早回答風險登記的 R1**：「準確率是不是全靠麥克風？」
按照 backlog 原本的排程，這個答案要等 `E05`（4 h 資料蒐集）+ `D13`（Silhouette）
才會出現，大約在第 11 天。`D21` 讓你在第 3–4 天就拿到一個粗略但方向正確的訊號。

**如果 ToF 軌的排名完全是隨機的，你會想在投入那 4 小時之前就知道。**

## 實作

### 🔴 最重要的一件事：3–4 秒的錄音裡，大部分是靜音

一個「八」大約 400–600 ms。錄 3.5 秒的話：

```
[───────── 3500 ms ─────────]
[ 靜音 1400 ][ 詞 500 ][ 靜音 1600 ]
                14%
```

**如果不裁切就直接算距離，86% 的向量是「靜音對靜音」——那部分永遠完美吻合，
把真正有差異的 14% 稀釋掉，所有選項的距離會擠成一團。**
你會看到 8 個選項的分數都是 12–13%，然後以為是 ToF 沒訊號。

實際上是你在比較兩段靜音。

所以 VAD 裁切**不是可選的前處理，是這個功能能不能成立的前提**：

```python
lips  = detect_lip_activity(...)      # B16
voice = detect_voice_activity(...)    # B15
# 取聯集，前後各留 100 ms padding
t0 = min(lips.start_us, voice.start_us) - 100_000
t1 = max(lips.end_us,   voice.end_us)   + 100_000
```

**silent 模式下 `voice` 會是 `None`**（`CONTRACTS.md` §2.2），此時只用 `lips`。
兩者都偵測不到 → **明確報錯並要求重錄**，不要靜默地把整個 3.5 秒視窗當成語音。

### 特徵管線

```python
# ToF：CONTRACTS §3.2，注意 SIGMA_FLOOR
SIGMA_FLOOR = 1.0 / math.sqrt(12)          # ← 不是 1e-3，見 §3.2.1
z = (tof - baseline_mu) / np.maximum(baseline_sigma, SIGMA_FLOOR)
z[~valid] = 0.0
z = z[:, active_zones]                      # D01，若 D11 還沒跑就用全部

# 音訊：CONTRACTS §3.1
mel = log_mel(audio)                        # Slaney, n_mels=40, 80–8000 Hz
mel = mel - mel.mean(axis=0, keepdims=True) # CMN

# 兩者都重採樣到固定長度
T = 24        # 單詞用 24；若選項是 1.5 s 以上的片語，提高到 48–64
```

### 距離

```python
def euclid(a, b):                 # a, b: (T, D)
    return float(np.linalg.norm(a.ravel() - b.ravel()))
```

**ToF 用歐氏距離要知道它的一個性質**：在 z-score 空間裡，歐氏距離對**幅度**敏感。
同一個詞念得大聲一點、嘴張大一點，即使形狀完全相同，距離也會變大。
餘弦距離則只看形狀、不看幅度。

所以請**同時算兩種並列印出來**——只多三行程式碼，而這個比較本身很有資訊量：

| 若… | 代表 |
|---|---|
| 歐氏明顯比餘弦好 | 幅度本身帶有判別資訊（不同詞的開口大小不同） |
| 餘弦明顯比歐氏好 | 幅度主要是雜訊（戴法、用力程度），該正規化掉 |
| 兩者差不多 | 用歐氏即可，符合你原本的指定 |

音訊建議也兩種都算。log-Mel 經過 CMN 之後幅度資訊已經被削掉大半，
兩者通常接近。

### 🔴 可分性預檢：在念探針之前就先做

錄完 N 個選項之後、**還沒念探針之前**，先算 enrollment 彼此的兩兩距離矩陣：

```python
D_enroll[i][j] = euclid(feat[i], feat[j])      # N×N，對角線為 0
```

這張表 30 秒就能算出來，而它會直接告訴你**這個任務可不可能成立**：

- 如果 `五` 和 `一` 在 ToF 空間裡的距離，跟 `五` 和 `五` 的自距離差不多
  → 這兩個選項**本來就分不開**，探針怎麼念都是擲骰子
- 如果整張矩陣的非對角線值都差不多大
  → ToF 對這組詞完全沒有判別力，該回頭檢查 `D11` 的 SNR 或戴法

**這比跑探針更有診斷價值**，因為探針失敗時你分不清是「探針念得不好」
還是「這些選項本來就不可分」。預檢把後者單獨隔離出來。

把矩陣印成熱力圖，對角線應該最暗（距離 0），非對角線越亮越好。

### 三軌排名

```python
d_tof_n = (d_tof - d_tof.min()) / (d_tof.std() + 1e-9)
d_mel_n = (d_mel - d_mel.min()) / (d_mel.std() + 1e-9)
d_fused = w * d_tof_n + (1 - w) * d_mel_n        # w 可調，預設 0.5
```

**兩個模態必須各自正規化後才能加權。** ToF 的歐氏距離與 Mel 的歐氏距離量級
可能差 10 倍，不正規化的話 `w=0.5` 實際上等於「幾乎只用其中一個」。

輸出：

```
探針：（實際念了「五」）                    N=8, 隨機基準 12.5%

  ToF only (歐氏)      Mel only            Fused w=0.5
  1. 五    d=2.14  ★   1. 五    d=1.87  ★   1. 五    ★
  2. 一    d=3.02      2. 四    d=2.41      2. 一
  3. 啊    d=3.55      3. 一    d=2.88      3. 四
  ...                  ...                  ...

  ToF 排名   1/8   （若接近 4.5 = 隨機）
  Mel 排名   1/8
```

**「ToF 的排名」這個數字比 top-1 對錯更有用**：單次探針的 top-1 只有對錯兩種
結果，資訊量太低；而「正確答案排在第幾名」在 8 個選項下有 8 種取值，
連續幾次探針就能粗略看出 ToF 是不是明顯優於隨機（平均排名應顯著低於 4.5）。

### 建議每個選項錄 2–3 次

錄 1 次的話，**一次咳嗽或講錯就會讓那個選項永久錯位**，而你不會知道。
錄 3 次的成本是 30 秒 → 90 秒，換來兩件事：

1. `d_class = min(dist(probe, t) for t in templates[c])` — 對壞樣板穩健
2. 可以算**同類自距離**（同一個詞的三次錄音彼此距離）作為分母：

```
可分性比值 = 最近的異類距離 / 同類自距離的中位數
```

這個比值 > 1.5 才算真的可分。它比絕對距離有意義得多，
因為絕對距離的尺度隨特徵維度變動，無法跨組態比較。

## 驗收條件

- [ ] 錄 N 個選項（N 可設，預設 8）各 3–4 秒，VAD 正確裁切出語音本體

- [ ] silent 模式（無發聲）下僅靠 ToF VAD 仍能裁切
- [ ] ToF 使用 `SIGMA_FLOOR = 1/√12`，非 `1e-3`（`CONTRACTS.md` §3.2.1）
- [ ] 歐氏與餘弦兩種距離並列輸出
- [ ] enrollment 兩兩距離矩陣熱力圖產出，對角線為 0
