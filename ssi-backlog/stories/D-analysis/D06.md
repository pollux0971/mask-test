## Story

**As a** 前端
**I want** 一組總和為 1 的分數與一個明確的拒識判定
**so that** 我能畫長條圖並顯示信心度

## 為什麼是這個順序

原始距離沒有絕對尺度（DTW 距離 12.3 是好是壞？）。轉成分數才能比較與顯示。而拒識讓系統能誠實說「我不知道」。

## 範圍

**包含**
- 每類距離 = 該類所有樣板的最小距離
- 距離正規化（減最小值除標準差）
- softmax 轉分數，溫度 τ 可調
- 拒識閾值由 enrollment 的靜止類別距離分布 p95 決定

**不包含**（避免範圍蔓延）
- 三軌融合（D07）

## 實作

**用 min 不用 mean。** 樣板品質不齊時（總有一兩筆錄壞的），mean 會被拖累而 min 不會。代價是對離群樣板敏感——所以 D08 的 LOOCV 要能找出壞樣板。

```python
d_class = np.array([min(dist(q, t) for t in templates[c]) for c in classes])
d_norm  = (d_class - d_class.min()) / (d_class.std() + 1e-9)
scores  = softmax(-d_norm / tau)
reject  = d_class.min() > theta_reject
```

**τ 的選擇會影響觀感**：τ 太小分數會極端（99% vs 0.3%），看起來過度自信；τ 太大分數會平坦（20% vs 15%），看起來沒信心。建議 τ=0.5 起步，然後**用實際的 Demo 錄影來調**——調到「對的時候明顯領先、不確定的時候看得出猶豫」。

`theta_reject` 從靜止類別的距離分布 p95 取，這樣約 5% 的真靜止會被誤判為有語音（可接受），而大部分非詞彙輸入會被正確拒絕。

## 驗收條件

- [ ] 分數總和為 1
- [ ] 靜止輸入的拒識率 > 90%
- [ ] 真實語音的誤拒率 < 10%
- [ ] τ 可調且效果符合預期
