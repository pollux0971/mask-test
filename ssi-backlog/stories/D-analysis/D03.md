# D03 — 特徵組裝與固定長度重採樣

| 欄位 | 值 |
|---|---|
| **軌道** | D 分析引擎 |
| **Epic** | E3 特徵 |
| **估時** | 2 h |
| **前置** | `D01`, `D02` |
| **阻擋** | `D04`, `C10` |
| **需要硬體** | 否 |
| **可平行於** | A/B/C 軌全部 |

## Story

**As a** 相似度引擎
**I want** 把 ToF 與 Mel 串接成統一的特徵序列，並提供固定長度版本
**so that** 我能先用最簡單的餘弦距離跑通管線

## 為什麼是這個順序

固定長度 + 餘弦是最簡單的相似度方案，5 分鐘就能寫完。先讓整條管線通，再考慮 DTW（D05）。**不要一開始就上 DTW**——那會讓你分不清問題出在特徵還是在對齊。

## 範圍

**包含**
- 依 T03 的順序串接（ToF_A / ToF_B / Mel）
- 線性重採樣到固定 T=24 幀
- PCA 擬合與投影（供 C10 使用）
- 回傳 `FeatureSeq(data, modality_slices, t_us)`

**不包含**（避免範圍蔓延）
- DTW（D05）
- 距離計算（D04）

## 實作

`modality_slices` 是這個資料結構的關鍵——D07 的三軌評分需要能單獨取出 ToF 或 Mel 的部分：

```python
@dataclass
class FeatureSeq:
    data: np.ndarray                    # (T, D)
    slices: dict                        # {"tof": slice(0,64), "mel": slice(64,104)}
    t_us: np.ndarray                    # (T,)
```

**T=24 的選擇**：ToF @30 Hz、詞長約 500 ms → 15 幀；Mel @62.5 Hz → 31 幀。24 是折衷，且對兩者都是溫和的重採樣。這個值應該做成參數，D05 完成後可實驗最佳值。

PCA 用 `sklearn.decomposition.PCA(n_components=2)`，擬合資料用 baseline + 一部分 trial。模型要能序列化（`joblib`）供 C10 跨 session 載入。
