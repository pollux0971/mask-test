## Story

**As a** 測驗模式
**I want** 同時輸出 ToF-only、Mel-only、Fused 三組分數
**so that** 我能證明 ToF 有獨立貢獻

## 為什麼是這個順序

**這是整個專案的科學核心。** 少了 sEMG 之後，最大的質疑是「準確率是不是全靠麥克風」。三軌並列讓這個問題永遠有答案。

## 範圍

**包含**
- 三組獨立的距離向量與分數
- 融合：`d_fused = w·d̃_ToF + (1-w)·d̃_Mel`
- 回傳結構要讓前端能只改 w 就重算（不需重新比對）
- 各軌的 top-1 與信心度

**不包含**（避免範圍蔓延）
- 前端顯示（C16/C17）

## 實作

**回傳結構的設計決定了 C17 滑桿能不能即時重算：**

```python
@dataclass
class TriResult:
    classes:  list[str]
    d_tof:    np.ndarray    # 已正規化的距離向量
    d_mel:    np.ndarray
    reject_tof: bool
    reject_mel: bool
    def fuse(self, w): return softmax(-(w*self.d_tof + (1-w)*self.d_mel) / tau)
```

回傳**正規化後的距離向量**而非分數，前端拿到就能自己算任意 w 的融合結果——這是 C17「拖滑桿不需重念」的前提。

**兩個模態的距離要各自正規化後才能加權。** ToF 的 DTW 距離與 Mel 的 DTW 距離量級可能差 10 倍，不正規化的話 w=0.5 實際上等於「幾乎只用其中一個」。

## 驗收條件

- [ ] 三軌分數各自正確
- [ ] `fuse(w)` 在 w=0 時等於純 Mel、w=1 時等於純 ToF
- [ ] 距離正規化後兩模態量級相當
- [ ] 前端能只用回傳結構重算任意 w
