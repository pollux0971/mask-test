## Story

**As a** Demo 演示者
**I want** enrollment 結束立刻知道樣板品質
**so that** 我不會在觀眾面前才發現 Demo 會翻車

## 為什麼是這個順序

**這個 story 是 Demo 的保險。** enrollment 完跑 LOOCV，30 秒就知道準確率。如果只有 30%，當場重錄或調戴法；如果 85%，安心上台。

## 範圍

**包含**
- 樣板存/載（`templates/<subject>_<wear_id>.npz`）
- leave-one-out 交叉驗證
- 逐樣板的「貢獻度」分析：移除它之後準確率變化
- 壞樣板標記與單筆重錄介面（配合 C14）

**不包含**（避免範圍蔓延）
- 即時辨識服務（D09）

## 實作

**逐樣板貢獻度是這個 story 最有價值的部分：**

```python
for c in classes:
    for k in range(n_templates):
        acc_without = loocv(templates_minus(c, k))
        contribution[c][k] = acc_without - acc_full
```

貢獻度為正的樣板（移除它反而更準）就是壞樣板——通常是錄的時候咳嗽、講錯、或戴法剛好跑掉。找出來重錄，準確率常常能跳好幾個百分點。

**跨 session 載入要警告。** 樣板是在特定 `wear_id` 下錄的，換一次戴上就可能失準。載入不同 `wear_id` 的樣板時明確提示「非同次戴上，準確率可能下降」。

- [ ] 跨 wear_id 載入時有警告
