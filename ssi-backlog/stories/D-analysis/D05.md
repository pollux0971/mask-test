## Story

**As a** 辨識引擎
**I want** 對語速變化穩健的距離度量
**so that** 同一個詞念快念慢都能正確比對

## 為什麼是這個順序

固定長度重採樣假設語速一致。實際上「不要」念快念慢差很多，而重採樣會把這個差異變成距離。DTW 允許非線性對齊。

## 範圍

**包含**
- 帶 Sakoe-Chiba 約束的 DTW（band ratio 預設 0.2）
- 可變長度輸入（不需重採樣）
- per-modality 版本
- 與 D04 的準確率比較報告

**不包含**（避免範圍蔓延）
- 分數轉換（D06）

## 實作

先試 `dtaidistance` 或 `tslearn`（`tslearn.metrics.dtw` 支援 multivariate 與 sakoe_chiba_radius）。若效能不足再用 numba 自己寫。

**Sakoe-Chiba band 不只是加速，更是正則化。** 沒有約束的 DTW 可以把「五」硬拗成「一」的形狀（極端的時間扭曲），反而降低判別力。band ratio 0.2 表示對齊路徑不能偏離對角線超過 20%。

**這個 story 的產出包含一份比較報告**：

| 方法 | LOOCV top-1 | 單次比對耗時 |
|---|---|---|
| 餘弦（T=24） | | |
| DTW (r=0.1) | | |
| DTW (r=0.2) | | |
| DTW (r=0.4) | | |

若 DTW 的提升 < 3 個百分點，**就用餘弦**——Demo 的即時性（C17 的滑桿要 < 50 ms 重算）比那 3 個百分點重要。
