## Story

**As a** 研究者
**I want** 六種模態組合的 Silhouette 分數
**so that** 我能在不用 ML 的前提下量化類別可分性

## 為什麼是這個順序

**`S(ToF_only)` 是整個專案最重要的一個數字。** 如果 `S(Mel)=0.6` 而 `S(ToF)=0.05`，那 ToF 沒有貢獻——這件事越早知道越好（第 11 天）。

## 範圍

**包含**
- 六種組合：ToF_L / ToF_R / ToF_Combined / Mel / All / (ToF vs Mel 差距)
- 標準流程：StandardScaler → PCA(50) → silhouette_score
- **silent 模式另外跑一組**
- 雙矩陣互補性：`S(Combined) > max(S(L), S(R)) + 0.05`

**不包含**（避免範圍蔓延）
- t-SNE 圖（D17）

## 實作

**silent 模式的那一組是最純粹的 ToF 測試。** 不出聲時 Mel 幾乎無資訊，此時的 Silhouette 完全來自 ToF——這是你的裝置能否用於「無聲介面」的直接證據，也是論文最有價值的一張表。

| 組合 | normal | whisper | **silent** |
|---|---|---|---|
| ToF_Combined | | | ← **這一格** |
| Mel | | | ← 應該接近 0 |
| All | | | |

判定標準（照簡報）：> 0.5 強分離 / 0.3–0.5 標準通過 / 0.15–0.3 邊緣可分 / < 0.15 失敗。

PCA 降到 50 維是為了讓歐氏距離在高維下仍有意義（維度詛咒）。這個值要記錄，因為它會影響結果。
