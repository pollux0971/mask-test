## Story

**As a** 研究者
**I want** 分別計算同一次戴上與跨次戴上的變異係數
**so that** 我知道戴法重複性是不是瓶頸

## 為什麼是這個順序

如果 `CV_between > CV_within × 1.5`，那戴法重複性就是主要問題——這會直接指向「要改進機械設計或 SOP」，而不是「要改進演算法」。診斷方向完全不同。

## 範圍

**包含**
- 依 `wear_id` 分組計算 within / between CV
- 分模態：ToF_L 距離 / ToF_R 距離 / signal rate / Mel 總能量
- 箱型圖視覺化
- `between / within` 比值與判定

**不包含**（避免範圍蔓延）
- 資料蒐集（E04）

## 實作

```python
within  = df.groupby("wear_id")[feat].agg(lambda x: x.std()/x.mean())
between = df.groupby("wear_id")[feat].mean().std() / df[feat].mean()
```

**這個實驗完全依賴 `wear_id` 的正確性**（B09/C11）。如果錄資料時 `wear_id` 填錯，這個實驗的結果就是垃圾——而且看不出來。所以 C11 的 wear_id UI 才需要特別設計。

失敗時的建議清單要具體：
- 骨架與臉部的接觸點增加（三點支撐 → 更穩定）
- 加定位標記（讓每次戴的位置一致）
- SOP 加入「戴上後先看 C09 的對稱性指標，調到綠燈才開始」
