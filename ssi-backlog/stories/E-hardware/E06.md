# E06 — Enrollment 與 LOOCV 驗收

| 欄位 | 值 |
|---|---|
| **軌道** | E 硬體實驗 |
| **Epic** | E6 Demo |
| **估時** | 1 h |
| **前置** | `E05`, `D08`, `C13` |
| **阻擋** | `E07` |
| **需要硬體** | **是** |
| **可平行於** | C/D 軌全部 |

## Story

**As a** Demo 演示者
**I want** 錄好樣板並當場驗證品質
**so that** 我上台前就知道 Demo 會不會翻車

## 為什麼是這個順序

這是 Demo 前的最後一道關卡。LOOCV 低於 60% 就不要上台——先找出壞樣板重錄，或調整戴法。

## 範圍

**包含**
- 8 詞 × 8 樣板 + 靜止 × 8 = 72 筆
- 當場跑 D08 的 LOOCV 與逐樣板貢獻度
- 壞樣板重錄
- 三軌各自的 LOOCV

**不包含**（避免範圍蔓延）

## 實作

**要看三軌各自的 LOOCV，不只看融合的。**

| 軌 | LOOCV | 意義 |
|---|---|---|
| Fused | 85% | Demo 主軌，> 75% 才安心上台 |
| Mel-only | 78% | 音訊基準 |
| **ToF-only** | **45%** | **> 12.5% 隨機基準就有意義，> 40% 很好** |

ToF-only 45% 看起來不高，但**隨機是 12.5%**——那是 3.6 倍。這個數字在 Demo 時要主動說出來。

如果 ToF-only 接近 12.5%，那 C17 的滑桿 Demo（推到純 ToF 仍認得出來）就做不成——這時要誠實調整 Demo 腳本，改成展示「ToF 在 silent 模式下的獨立價值」。

## 驗收條件

- [ ] 72 筆樣板完成
- [ ] Fused LOOCV > 75%
- [ ] ToF-only LOOCV 明顯高於 12.5%
- [ ] 壞樣板已找出並重錄
- [ ] 樣板已存檔可重載
