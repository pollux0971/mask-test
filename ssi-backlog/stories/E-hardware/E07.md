## 實作

**四步 Demo 腳本**：

1. `w = 0.5` 念「五」→ 三軌都對 → 「系統認得出來」
2. **滑桿推到 `w = 1.0`（純 ToF）→ 再念「五」→ 仍然對** → 「而且不靠聲音」
3. **用氣音念「五」（silent）→ Mel 軌崩潰、ToF 軌仍對** → 全場最強的一擊
4. **純 ToF 念「四」→ 認不出來** → 「這是 ToF 的能力邊界，所以需要多模態」

第 4 步主動展示失敗，反而大幅提升可信度。**委員最怕的是看到一個永遠成功的 Demo。**

Q&A 準備（沿用簡報第 17 頁 + 兩題新的）：
- 「為何 2 顆 VL53L7CX 而非 1 顆密集矩陣？」
- 「兩顆不會 crosstalk 嗎？」
- 「怎麼證明不是過擬合？」
- **「沒有 sEMG 會不會影響結論？」** → 單通道 sEMG 對 mentalis 訊號本就有限，移除後改以 ToF-only 消融（D19）作為主要論證，嚴謹度不減反增
- **「怎麼證明不是麥克風在做事？」** → 現場滑動融合權重 + silent 模式 Demo
