# B10 — Session baseline 自動錄製

| 欄位 | 值 |
|---|---|
| **軌道** | B 主機橋接 |
| **Epic** | E2 資料集 |
| **估時** | 1.5 h |
| **前置** | `B09`, `B06` |
| **阻擋** | `D01`, `C06` |
| **需要硬體** | 否 |
| **可平行於** | A/C/D 軌全部 |

## Story

**As a** 特徵正規化與實驗 A
**I want** 每個 session 開始時自動錄 30 秒靜止基線
**so that** z-score 與 SNR 都有同次戴上的參考點

## 為什麼是這個順序

基線必須是**同一次戴上**時錄的。跨次戴的基線會把戴法差異混進正規化裡，讓所有下游數字失真。強制自動錄製比依賴人記得做可靠得多。

## 範圍

**包含**
- session start 後強制進入 30 秒 baseline 擷取
- 計算 per-zone 的 μ 與 σ，寫進 `/meta`
- 擷取期間偵測異常（若受試者動了，σ 會異常大）並允許重錄
- 以 `label=_baseline` 存成 trial_000

**不包含**（避免範圍蔓延）
- 前端倒數 UI（C11）

## 實作

異常偵測：計算基線期間的 per-zone σ，若任一 zone 的 σ > 2 mm，代表受試者在動或戴法不穩。這時**不要靜默接受**——回報並要求重錄。

```python
if (sigma > 2.0).any():
    return {"ok": False, "reason": "baseline unstable",
            "unstable_zones": np.where(sigma > 2.0)[0].tolist()}
```

回報哪些 zone 不穩很有用：如果只有邊角 zone 不穩，可能是那幾個 zone 本來就在量測邊緣（沒有目標），可以接受；如果是中央 zone 不穩，那就是真的在動。

同時記錄音訊底噪的 μ 與 σ，供 VAD（B15）的閾值使用。

## 驗收條件

- [ ] μ / σ 正確寫進 `/meta`

- [ ] 音訊底噪統計一併記錄
