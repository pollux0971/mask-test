| 欄位 | 值 |

| **軌道** | B 主機橋接 |
| **Epic** | E3 音訊特徵 |
| **估時** | 2 h |
| **前置** | `B15`, `B10` |
| **阻擋** | `B13`, `D14` |

## Story

**As a** silent 模式與研究觀察
**I want** 從 ToF 訊號偵測唇動起訖
**so that** 不出聲時仍能切出動作區間，並量測唇動與發聲的時間差

## 為什麼是這個順序

silent 模式（不出聲）下音訊 VAD 完全失效，但那正是這個裝置最有價值的應用場景。而且唇動通常比發聲早 50–150 ms——**這個時間差本身就是一個值得寫進論文的觀察**。

## 範圍

**包含**
- 以活躍 zone 的 z-score 能量作為 ToF-VAD 訊號源
- 同樣的雙閾值遲滯
- 計算 `lip_onset_us - voice_onset_us` 並寫進 trial attrs

**不包含**（避免範圍蔓延）
- 活躍 zone 的篩選（D01，此處先用全部 zone）

## 實作

```python
energy = np.abs(zscore(tof, baseline_mu, baseline_sigma)).mean(axis=1)
```

先用全部 zone 的平均。D01 完成後可以改用 SNR > 2 的活躍 zone，訊噪比會更好——但**不要等 D01**，先用簡單版把管線跑通。

唇動先行的量測要小心一個陷阱：如果 ToF-VAD 的閾值比音訊 VAD 寬鬆，會系統性地產生「唇動比較早」的假結果。驗收時要用一個對照：**播放錄音給裝置聽**（此時沒有唇動），確認 ToF-VAD 不會誤觸發。

這個數字若穩定為正且有統計顯著性，是很好的論文素材：「本系統的 ToF 通道平均較音訊通道早 X ms 偵測到發音起始，顯示視覺模態在時序上具備前導性。」
