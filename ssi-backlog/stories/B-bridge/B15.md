# B15 — 音訊 VAD 端點偵測

| 欄位 | 值 |
|---|---|
| **軌道** | B 主機橋接 |
| **Epic** | E3 音訊特徵 |
| **估時** | 2 h |
| **前置** | `B10` |
| **阻擋** | `B13`, `B16`, `D02` |
| **需要硬體** | 否 |
| **可平行於** | A/C/D 軌全部 |

## Story

**As a** 特徵抽取
**I want** 自動找出一段錄音中詞的起訖位置
**so that** DTW 比對的是語音本體，不是前後的靜音

## 為什麼是這個順序

前後靜音長度不一會讓 DTW 把「靜音對齊靜音」也算進距離，稀釋掉真正的差異。切乾淨能明顯提升辨識率。

## 範圍

**包含**
- 雙閾值遲滯：`baseline + 3σ` 進入、`baseline + 1.5σ` 且持續 200 ms 離開
- 閾值由 B10 的底噪統計自動決定
- 回傳 `(start_us, end_us)` 與信心度

**不包含**（避免範圍蔓延）
- ToF VAD（B16）

## 實作

遲滯（hysteresis）是關鍵：單一閾值會在音量接近閾值時瘋狂抖動，把一個詞切成好幾段。

**閾值必須來自 B10 的當次 session 底噪，不能寫死。** 不同環境（實驗室 vs 家裡）、不同戴法（骨傳導接觸鬆緊）的底噪差很多，寫死的閾值在換環境後就失效了。

whisper 模式的音量遠低於一般說話，`3σ` 可能太嚴格——建議讓閾值倍數可依 `mode` 調整：`normal` 用 3σ、`whisper` 用 2σ、`silent` 直接不用音訊 VAD。

## 驗收條件

- [ ] 對 20 筆人工標註的錄音，邊界誤差 < 100 ms
- [ ] whisper 模式下漏偵率 < 10%
- [ ] 閾值從 session 底噪自動計算，換環境無需手調
