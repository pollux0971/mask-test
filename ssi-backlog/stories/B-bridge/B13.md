# B13 — Auto-VAD 觸發

| 欄位 | 值 |
|---|---|
| **軌道** | B 主機橋接 |
| **Epic** | E2 資料集 |
| **估時** | 2 h |
| **前置** | `B11`, `B15` |
| **阻擋** | `C15` |
| **需要硬體** | 否 |
| **可平行於** | A/C/D 軌全部 |

## Story

**As a** 測驗模式
**I want** 系統自動偵測我開始說話並擷取
**so that** Demo 時不用一手按鍵一手比劃

## 為什麼是這個順序

測驗模式（C15）的互動應該是「看到題目 → 直接念出來 → 立刻看到結果」。中間插一個按鍵會破壞流暢感，而 Demo 的流暢感很影響觀感。

## 範圍

**包含**
- 以 B15 的 VAD 為觸發源
- 偵測到語音起點往前回溯 300 ms 開始擷取
- 靜音 400 ms 後結束
- 冷卻期避免連續誤觸

**不包含**（避免範圍蔓延）
- VAD 演算法本身（B15）

## 實作

**silent 模式下音訊 VAD 會失效**（不出聲），所以觸發源要能切換到 ToF-VAD（B16）。這在測驗模式的 Demo 腳本第三步「用氣音念五」時是必要的。

```python
TRIGGER_SOURCE = {"audio": ..., "tof": ..., "either": ...}
```

`either` 模式取兩者的聯集：任一偵測到就觸發。這對 whisper 模式最穩健（音量小但唇動明顯）。

冷卻期 800 ms，避免一個詞被切成兩段。

## 驗收條件

- [ ] 正常音量下誤觸發率 < 1 次/分鐘（安靜環境）
- [ ] silent 模式下切到 ToF 觸發源仍能運作
- [ ] 觸發到擷取開始的延遲 < 50 ms
